Hosting Render free tier (compute) + Turso free tier (storage). Runs at $0/mo.
Cold start If nobody's used the site in 15+ minutes, Render puts the container to sleep. Your first request wakes it — expect ~1 minute of Render's loading screen. Every request after that is instant until the next quiet period.
Permalinks Every analysis is stored in Turso, so shareable links survive the container sleeping and every redeploy. Old runs load in under a second once the container's awake.
Cost cap Analysis is limited to 5 tickers so nobody can run up the LLM bill. Clone the repo and set your own GROQ_API_KEY to analyze anything.
Trade-off Paying ~$0.20/mo on Fly.io would eliminate the cold start entirely. Chose $0 with a slower first-visit over pennies with instant response — it's a portfolio demo, not a production app.
